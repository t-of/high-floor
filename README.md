# HIGH FLOOR — 一番損する人を出さない割り当て

部屋割りや係決めで、みんなが持ち点 100 点を行きたい先に配って、1 台の端末を回して入れる。一番点の低い人ができるだけ高くなる組み合わせを、端末の中だけで計算して出す。

## 🔗 リンク

- 使う: https://t-of.github.io/high-floor/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 「新しく決める」で、決めたいこと（例: 部屋割り）と、行き先（和室 4 人・洋室 2 人…）と、参加者を入れる。名前は空でもよい。
2. 端末を 1 人ずつ回す。自分の番の人は、持ち点 **100 点**を行きたい先に多く配る。
   - かんたん: 行き先ごとに ◎ ○ △ ✕ を付ける（◎ 8・○ 4・△ 2・✕ 0 の比で 100 点に分ける）
   - こまかく: −10 / −1 / +1 / +10 で配る。「均等にする」「残りを一番高い所へ」もある
   - 入れ終わると「次の人に渡してください」だけの画面になり、前の人の点は見えない
3. 全員が入れたら「割り当てる」。**一番点の低い人ができるだけ高くなる**組み合わせを選び、そのうえで全員の点の合計が一番高いものを出す。同じくらい公平な組み合わせがほかにもあれば「引き直す」で変わる（一番低い点と合計は変わらない）。

参加者 2〜30 人、行き先 2〜10 か所、定員 1 か所 1〜30 人。名前と希望はこの端末の中（localStorage）にだけ置き、通信しない。
共有ボタンで外に出るのは、割り当ての顔ぶれと一番低い人の点だけ。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
npm test                      # 配り方と割り当ての計算のテスト（node --test）
```

| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` / `main.js` | 画面 |
| `logic.js` | 持ち点の配り方（最大剰余法）、割り当ての計算、記録の読み込み |
| `test/logic.test.mjs` | 小さい問題 400 個を全部試した答えと比べる、仕様の例、一番大きい場合の時間 |

割り当ての計算: 行き先を定員の数だけ席に分け、人 × 席 の表にする。
段階 1 で「全員が t 点以上の席に座れるか」を二分探索（判定は増加路法の完全マッチング）して最小値を決め、
段階 2 で t 点未満の席を禁止にしてハンガリー法で合計を最大にする。同点は、人と席の並びを種で並べ替えて選ぶ（「引き直す」で種 +1）。
30 人・10 か所・席 300 で数ミリ秒。

保存するもの（localStorage）: `high-floor.sessions`（記録。新しい順に 20 件まで）、`high-floor.settings`（音のオン・オフ）。
